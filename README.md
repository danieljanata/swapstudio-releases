# SwapStudio

Swap a face into videos, or bring a photo to life with a video's movement — on a graphics card
rented on [vast.ai](https://vast.ai) only while it works. Mac app (Apple Silicon and Intel, macOS 12 Monterey or newer).

## Install

1. Download **[SwapStudio.dmg](https://github.com/danieljanata/swapstudio-releases/releases/latest/download/SwapStudio.dmg)**.
2. Open it and drag **SwapStudio** into **Applications**.
3. Open SwapStudio from Applications. The first time macOS says it cannot verify the app — click **Done**,
   then open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**
   (on macOS 14 or older: right-click SwapStudio → **Open** → **Open**). Only needed once.
4. Make an account on [cloud.vast.ai](https://cloud.vast.ai), add credit ($10 is plenty to start),
   create an API key (**Keys → + New**) and paste it into SwapStudio.

The full guide with all steps is inside the download (`How to open SwapStudio.pdf`).

## Updates

SwapStudio updates itself: when a new version is out, a bar at the top of the app says **Update now**.
Every update is signed — the app installs nothing else.

This repository only hosts the releases.
